# ZARQ — Footwear storefront

A responsive, static storefront foundation for the ZARQ premium Peshawari footwear brand.

## Files
- `index.html` — page structure and content
- `style.css` — responsive black-and-gold visual system
- `script.js` — mobile navigation and basic page behavior

## Current launch state
This is a visual foundation only. The product collection, cart, checkout, payments, customer records and admin tools are intentionally not activated. No sample prices, sizes, product claims or customer order flow are invented.

## Local preview
Open `index.html` in a browser.

## Cloudflare Pages
For a plain static site connected to this repository:
- Framework preset: None
- Build command: leave empty
- Build output directory: `/` (if the dashboard accepts it; otherwise use `.`)
- Root directory: `/` or repository root
- Do not use `npx wrangler deploy` as a Pages build command.

Add actual product photography, product names, prices, available sizes/colors and business policies before enabling sales.
